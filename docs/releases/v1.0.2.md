# Tube NEXT v1.0.2

Hotfix fuer einen Release-Startabsturz auf echten arm64-Geraeten.

## Aenderungen

- Behebt einen nativen GeckoView-Absturz direkt beim App-Start.
- Release-Builds werden vorerst wieder ohne R8-Minify und Resource-Shrinking
  gebaut.

## Hintergrund

`v1.0.1` aktivierte R8-Minify und Resource-Shrinking fuer Release-Builds. Auf
dem Galaxy S24 Ultra fuehrte der minifizierte arm64-Build beim Start zu einem
nativen Crash in GeckoView/`libxul.so`. Der gleiche Release-Build ohne R8
startet auf dem Geraet stabil.

Die funktionalen Aenderungen aus `v1.0.1` bleiben enthalten:

- stabilere Tab-Vorschaubilder
- weniger Hintergrundarbeit durch lazy geladene wiederhergestellte Tabs
- Tab-Manager schliesst sich nach normalem Tab-Tap
- Debug- und Release-App-IDs sind getrennt
