# Tube NEXT v1.3.7

Dieses Patch-Release verhindert ein unbeabsichtigtes technisches
YouTube-Kontextmenue beim Zoomen im immersiven Landscape-Player.

## Aenderungen

- Das Kontextmenue wird frueh in der Ereigniskette abgefangen.
- YouTubes technisches Player-Menue wird im Landscape-Vollbild zusaetzlich
  ausgeblendet.
- Die bestehende Cue-Long-Press-Funktion auf der freien Videoflaeche bleibt
  erhalten.

## APK-Auswahl

- `arm64-v8a`: moderne Android-Smartphones und -Tablets, darunter aktuelle
  Samsung-Geraete
- `armeabi-v7a`: aeltere 32-Bit-ARM-Geraete
- `x86_64`: Android-Emulatoren und manche Chromebooks
- `x86`: aeltere Emulatoren oder Intel-Android-Geraete

Die Datei `SHA256SUMS-v1.3.7.txt` enthaelt die SHA-256-Pruefsummen aller APKs.
