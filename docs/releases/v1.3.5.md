# Tube NEXT v1.3.5

Dieses Release aktualisiert GeckoView deutlich, um schwarze Tabs nach Resume oder Tabwechsel auf aktuellen Android-/Samsung-Geraeten zu vermeiden.

## Aenderungen

- GeckoView wurde von `136.0.20250317200840` auf `151.0.20260601110758` aktualisiert.
- `compileSdk` wurde auf 36 angehoben, damit die aktuelle GeckoView-/AndroidX-Basis sauber gebaut werden kann.
- `targetSdk` bleibt bei 35; das Release optiert nicht in zusaetzliche Android-36-Laufzeitveraenderungen ein.
- Die bestehende Render-Healthcheck-Logik bleibt erhalten und profitiert von der aktualisierten Gecko-Compositor-/Surface-Basis.

## APK-Auswahl

- `arm64-v8a`: moderne Android-Smartphones und -Tablets
- `armeabi-v7a`: aeltere 32-Bit-ARM-Geraete
- `x86_64`: Android-Emulatoren und manche Chromebooks
- `x86`: aeltere Emulatoren oder Intel-Android-Geraete

Tube NEXT waehlt in der integrierten Updateverwaltung automatisch die passende APK aus, sofern die ABI im Dateinamen steht.
