# Tube NEXT v1.4.8

Dieses Patch-Release verbessert den Umgang mit Googles Sicherheitspruefung
bei ungewoehnlichem Netzwerkverkehr.

## Sicherheitspruefung und Videostart

- Die Google-Seite `Ich bin kein Roboter` bleibt beim Oeffnen eines
  YouTube-Videos innerhalb von Tube NEXT.
- Auch das Absenden der reCAPTCHA-Pruefung bleibt im selben App-Tab, statt
  eine unvollstaendige Sorry-Seite im Systembrowser zu oeffnen.
- Nach erfolgreicher Pruefung wird das angeforderte Video wieder als
  Desktop-Watch-Seite mit dem fuer Smartphones angepassten Layout geladen.
- Andere Google-Seiten und ungueltige externe Ruecksprungziele bleiben von
  der engen Ausnahme ausgeschlossen.

Die identisch signierten APKs aktualisieren Tube NEXT ohne Verlust von Login,
Tabs oder Einstellungen. `SHA256SUMS-v1.4.8.txt` enthaelt die Pruefsummen
aller APK-Dateien.

## Diagnoseabgrenzung

- Die abgeschlossene Fullscreen-Fortschrittsdiagnose ist im regulaeren Release
  deaktiviert.
- Eine Diagnosevariante wird nur fuer eine ausdruecklich reaktivierte und neu
  angepasste Diagnosekampagne gebaut.
