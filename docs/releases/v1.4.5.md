# Tube NEXT v1.4.5

Dieses Release ergaenzt auf Wunsch geschaetzte Dislike-Zahlen von Return
YouTube Dislike. Die Funktion bleibt standardmaessig deaktiviert und wird erst
nach einem ausdruecklichen Datenschutzhinweis eingeschaltet.

## Geschaetzte Dislikes

- Unter `Einstellungen` -> `Watch-Seite` kann die Anzeige optional aktiviert
  werden.
- Vor der ersten Aktivierung erklaert Tube NEXT, welche Daten an Return
  YouTube Dislike uebermittelt werden und dass der Dienst daraus ein Nutzungs-
  oder Interessenprofil ableiten koennte.
- Die Zahlen sind Schaetzungen von Return YouTube Dislike und keine
  offiziellen YouTube-Werte.
- Die Zahl erscheint platzsparend direkt im vorhandenen Dislike-Segment der
  Watch-Seite.
- Eigene Like- und Dislike-Entscheidungen werden mit einer zufaellig erzeugten
  pseudonymen RYD-ID an den Dienst zurueckgemeldet. Die sichtbare Zahl reagiert
  unmittelbar auf den von YouTube bestaetigten Button-Zustand.
- Tube NEXT uebermittelt bei den RYD-Anfragen keine YouTube-Cookies und keinen
  Referrer.

## Schonender API-Zugriff

- Gleichzeitige Abrufe desselben Videos werden zusammengefasst und Ergebnisse
  zwischengespeichert.
- Lokale Minuten- und Tagesgrenzen liegen deutlich unter den vom Dienst
  genannten API-Limits und bleiben auch ueber App-Neustarts erhalten.
- Reine Zaehlerabrufe erzeugen bei Fehlern keine automatische
  Wiederholungsschleife.
- Bei einer serverseitigen Begrenzung wird `Retry-After` beachtet; bis dahin
  kontaktiert Tube NEXT den Dienst nicht erneut.
- Beim Ausschalten werden laufende RYD-Anfragen abgebrochen und ausstehende
  Stimmen verworfen.

Weitere Informationen zum verwendeten Dienst gibt es auf der
[Webseite von Return YouTube Dislike](https://returnyoutubedislike.com).

## Diagnoseabgrenzung

- Die zusaetzliche Fullscreen-Fortschrittsdiagnose bleibt im regulaeren
  Release deaktiviert.
- Eine gleich versionierte Diagnosefassung wird nur auf dem bekannten
  Testtelefon eingesetzt und nicht als GitHub-Asset veroeffentlicht.
