# Tube NEXT v1.1.0

Feature-Release mit Startseiten-Filtern fuer YouTube.

## Neu

- Neues Drei-Punkte-Menue rechts neben dem Tab-Manager.
- Startseiten-Filter mit gespeicherten Optionen:
  - Shorts anzeigen/ausblenden
  - Community-Posts anzeigen/ausblenden
  - Zuletzt gesehen anzeigen/ausblenden
- Filter werden live an laufende GeckoView-Tabs uebergeben.
- Mobile YouTube-Startseite (`m.youtube.com`) wird jetzt ebenfalls erkannt.
- Mobile Community-Posts und mobile Shorts-Regale werden defensiv ausgeblendet,
  wenn der jeweilige Haken entfernt ist.

## Hinweise

- Die Filter arbeiten als UI-Aufraeumfilter auf der offiziellen YouTube-Seite.
- Werbung wird nicht gefiltert.
- Die Erkennung bleibt bewusst konservativ, damit normale Video-Karten nicht
  versehentlich verschwinden.
- Release-Builds bleiben vorerst ohne R8-Minify, weil GeckoView 136 auf echten
  arm64-Geraeten mit minifizierten Release-Builds nativ abstuerzen kann.
