# Tube NEXT v1.3.0

Dieses Release bringt die erste integrierte Updateverwaltung für GitHub-/Sideload-Installationen.

## Änderungen

- Tube NEXT prüft beim Start und danach mindestens einmal täglich im laufenden App-Prozess auf neue GitHub-Releases.
- Die Updateverwaltung zeigt aktuelle und neue Version, das passende APK für die Geräte-ABI, Download-Status und Installationsaktionen.
- Update-APKs können direkt aus GitHub Releases heruntergeladen und über den Android-Paketinstaller gestartet werden.
- Vor Download und Installation prüft Tube NEXT die Android-Freigabe für „Unbekannte Apps installieren“ und bietet einen direkten Link zur Systemeinstellung.
- Nach einem Update erinnert Tube NEXT optional daran, die Installationsfreigabe wieder zu deaktivieren.
- Update-Hinweise können pro Version oder dauerhaft ausgeblendet werden.
- Release Notes öffnen in einem neuen Tube-NEXT-Tab statt im Systembrowser.
- Der Drei-Punkte-Button öffnet jetzt eine Einstellungsseite mit Startseiten-, Watch-Seiten- und Update-Bereich.

## Hinweise

- Für die automatische Auswahl des richtigen APKs müssen GitHub-Release-Assets die ABI im Dateinamen enthalten, zum Beispiel `arm64-v8a`, `armeabi-v7a`, `x86` oder `x86_64`.
- Die eigentliche Installation bleibt bewusst beim Android-Systeminstaller. Tube NEXT lädt nur herunter, prüft Berechtigungen und übergibt das APK.
- Release-Builds bleiben weiterhin ohne R8-Minify, weil GeckoView 136 auf echten arm64-Geräten mit minifizierten Release-Builds nativ abstürzen kann.
